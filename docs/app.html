Real client-side simulation — environment, belief filter, agent policies and metrics run entirely in this single self-contained file (no server, no network). Multiple fitted NSCLC stratifications are embedded inline and selectable. Edit controls, then press ▶ Run.

Research use only. Not validated for clinical use and not medical advice. The matrices are aggregate estimates derived from AACR Project GENIE BPC NSCLC data.
