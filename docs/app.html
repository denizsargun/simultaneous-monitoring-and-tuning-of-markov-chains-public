Cases

Build the cases in the sidebar. Each case is a true category, a tuning policy and an initial state; the cohorts come from the data set selected in the sidebar. All cases share the sidebar's horizon, Monte Carlo runs and α and the ⚙ Settings, and use the same random seeds; every patient of a case starts in its initial state. Up to 8 cases.

Averages by case

Weeks, over the Monte Carlo runs. A percentile of ≥ horizon is not reached within the horizon; a mean marked ≥ counts the runs without the event as the horizon, so the true mean is at least that.

Real client-side simulation — environment, belief filter, agent policies and metrics run entirely in this single self-contained file (no server, no network). Multiple fitted NSCLC stratifications are embedded inline and selectable. By default the agent measures the state every step and knows the true cohort; ⚙ Settings changes that. Edit controls, then press ▶ Run.

Research use only. Not validated for clinical use and not medical advice. The matrices are aggregate estimates derived from AACR Project GENIE BPC NSCLC data. ⚙ Settings

Random seed

One seed drives the single patient run, the Monte Carlo runs (run r uses seed + r·2654435761) and the compared cases. The status shows the seed each run used, so a run can be repeated by fixing it here.

Monitoring policy — when to measure

Measure the next state whenever the entropy of the agent's state belief is at least this; 0 measures every step.

Value iteration on the true cohort's untreated baseline, solved once: a measure or don't-measure decision per state, applied to the most likely state. Needs the category known.

Agent

Off: the agent starts from a uniform prior over the cohorts and infers the cohort with its belief filter; every action the selection can apply must then be fitted for every cohort. Always on for dynamic programming.

Costs

Per measurement and per change of the chosen action; summed in Overall cost (Multi-patient averages › Additional metrics).

Desired distribution π*

The target state distribution; must sum to 1. Used by the argmax selection, the dynamic-programming policy and JSD to Desired Distribution.
